# Flashcard Quiz App

A simple and responsive flashcard quiz app built with HTML, CSS, and JavaScript.

## Features
- View the question on the front of each flashcard.
- Click **Show Answer** to reveal the answer.
- Navigate using **Previous** and **Next**.
- Add custom flashcards.
- Edit and delete existing flashcards.
- Save flashcards locally in the browser using `localStorage`.
- Responsive interface for desktop and mobile.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run
1. Download `flashcard_quiz_app.html`.
2. Open the file in any modern web browser.
3. Start studying or add your own flashcards.
